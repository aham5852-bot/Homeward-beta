# Homeward Beta

A builder-first, buyer-facing prototype.

Core product model:
- Builder is the paying/controller customer.
- Buyer is the ultimate user.
- Builder defines projects, home types, templates and buyer data.
- Homeward personalizes the buyer experience based on home type, lot, upgrades and closing date.
- Buyer sees only the tasks and documents relevant to their purchase.

## What to test
1. Dashboard -> Buyers -> open a buyer.
2. Preview the buyer portal.
3. Change/complete tasks and watch readiness change.
4. Open Task templates and switch home types.
5. Review Documents, Messages and Projects.
